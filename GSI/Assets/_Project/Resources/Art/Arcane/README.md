# Arcane UI Backgrounds

The dark academy UI uses procedurally generated sprites from `GsiArcaneUi`.

The image generation tool was unavailable in this environment, so the runtime creates:

- `GSI_ArcaneBackground`
- `GSI_ArcaneLayer_1`
- `GSI_ArcaneLayer_2`
- `GSI_ArcaneLayer_3`

These sprites are deterministic and shared by all runtime scenes. Replace this folder with authored PNGs later if a final art pass is needed; keep the same visual direction: obsidian, brass, parchment, candlelight, and subtle rune geometry.
